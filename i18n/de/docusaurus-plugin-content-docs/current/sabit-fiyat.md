# Festpreise pro Produkt

Bei manchen Produkten möchtest du vielleicht einen runden, selbst festgelegten Preis anzeigen statt des Betrags, der sich aus der Wechselkursumrechnung ergibt. Das erledigst du im Produkteditor.

## Einfache Produkte

1. Bearbeite das Produkt.
2. Öffne in der Box **Produktdaten** den Tab **Währungspreise**.
3. Du siehst ein Feld pro konfigurierter Währung – gib dort den gewünschten Preis ein.
4. Aktualisiere das Produkt.

Felder, die du leer lässt, verwenden die automatische Wechselkursumrechnung (als Erinnerung steht im Platzhalter des Feldes **Automatisch**). Wenn du noch keine Währungen hinzugefügt hast, zeigt der Tab stattdessen einen Hinweis, der dich zur Einstellungsseite führt.

## Variable Produkte

Bei variablen Produkten hat die Preiszeile jeder Variante eigene Felder **Festpreise je Währung**. Die dort eingegebenen Werte gelten nur für diese Variante.

Wenn du für eine Währung einen Festpreis festlegst, werden der reguläre Preis **und** der Angebotspreis dieses Produkts auf denselben einzelnen Wert gesetzt. Wenn du für eine Währung ein Angebot anzeigen möchtest, lege für sie keinen Festpreis fest.
