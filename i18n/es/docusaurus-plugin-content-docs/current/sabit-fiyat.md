# Precios fijos por producto

Para algunos productos puede que quieras mostrar un precio redondo que fijes tú mismo, en lugar del que resulte de la conversión según el tipo de cambio. Esto se hace desde el editor de productos.

## Productos simples

1. Edita el producto.
2. En la caja **Datos del producto**, abre la pestaña **Precios por moneda**.
3. Verás un campo por cada moneda configurada: introduce el precio que quieras.
4. Actualiza el producto.

Los campos que dejes vacíos recurren a la conversión automática según el tipo de cambio (el texto de ejemplo del campo indica **Automático** para recordártelo). Si todavía no has añadido ninguna moneda, la pestaña muestra en su lugar una nota que te remite a la página de ajustes.

## Productos variables

En los productos variables, la fila de precios de cada variación tiene sus propios campos de **Precios fijos por moneda**. Los valores que introduzcas ahí solo se aplican a esa variación.

Si estableces un precio fijo para una moneda, el precio normal **y** el precio rebajado de ese producto pasan a ser el mismo valor único. Si quieres mostrar una rebaja en una moneda, no le establezcas un precio fijo.

Las preguntas frecuentes completas están en la página de [Preguntas frecuentes](/docs/faq); la lista completa de limitaciones conocidas está
en la página de [Limitaciones conocidas](/docs/known-limits).
