# Known limits

These are consequences of how cache compatibility mode works — search engines seeing base-currency prices, the mini-cart depending on WooCommerce's cart fragments, `?currency=` links multiplying cache entries, and more — not defects. The full list of ten is in the Known limits section of [readme.txt on GitHub](https://github.com/MaxHandMade/mhm-currency-switcher/blob/develop/readme.txt).
