# Fixed prices per product

For some products you may want to show a round price you set yourself, instead of whatever the exchange rate conversion produces. You do that from the product editor.

## Simple products

1. Edit the product.
2. In the **Product data** box, open the **Currency Prices** tab.
3. You'll see one field per configured currency — enter the price you want.
4. Update the product.

Fields you leave empty fall back to automatic exchange-rate conversion (the field's placeholder reads **Auto** to remind you). If you haven't added any currencies yet, the tab shows a note pointing you to the settings page instead.

## Variable products

For variable products, each variation's pricing row has its own **Fixed Currency Prices** fields. Values entered there apply only to that variation.

Setting a fixed price for a currency makes that product's regular price **and** its sale price equal to the same single value. If you want to show a sale for a currency, don't set a fixed price for it.
